# modsim
The GUI for ModSIm is written in Visual Basic.  We used Visual Studio 6.0 at the time, and the Visual Basic Project is in the ModSIm/Modsimvb folder. 

The DLL for ModSIm is written in FORTRAN.  We used Compaq Visual FORTRAN at the time, and the CVF project is in the ModSIm/Modsimdl folder.  Currently Intel Visual FORTRAN should be used instead but you will need the IMSL libraries for full functionality.

The graphics package needed for drawing flowsheets and plotting things in MoSim is Vetgraph.  This is also a Visual Basic 6.0 project in the Vetrgraph folder.  

An installation for this version 3.6.24 can be downloaded from the release section
