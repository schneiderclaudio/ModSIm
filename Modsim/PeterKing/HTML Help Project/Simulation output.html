The flowrates of total solids, water and minerals as well as grades of minerals or individual metals can be obtained by viewing the Simulation results from the View menu. Data from this file can be cut and pasted into standard spreadsheets for additional processing. The results of the simulation can be viewed as a text file by selecting Data output file from the View menu. This file can be saved as a text file or cut and pasted into any word processor for use in project reports for example.

Detailed output is available directly from the View Flowsheet screen. Right click on any unit icon or stream to access full details of that unit or stream.
