VJIG: Model for a single stage jig based on the equilibrium stratification model.

The equilibrium stratification profile for each particle type is calculated and is available from the model in graphical form. This is accessed by right clicking the unit icon when viewing the flowsheet and selecting Stratification profiles from the pop-up menu.
