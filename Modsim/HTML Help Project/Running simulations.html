The operation of a plant can be simulated once the flowsheet has been defined, the system data has been specified, models have been selected for each unit in the flowsheet and the operating parameters for each unit model have been specified.

The simulation can be run by selecting the run simulation item from the run menu on the main Modsim screen. In most cases running the simulation can be controlled most effectively from the View Flowsheet screen. This screen shows the material balance for the latest run of the simulation and virtually any information that is required about the individual units or any stream in the flowsheet can be obtained directly form this screen. Right click on any unit icon or on any stream to show a popup menu from which any particular type of information can be selected. Use this menu to change the model or the model parameters for any model before running another simulation. The simulation can be run directly from this screen by right clicking on any blank point of this screen. Variations of the total material flows are immediately visible since these are updated as soon as the simulation is complete
