The MODSIM simulator consist of the following components.

MODSIM - the plant simulator.

ModCurvefit - a search engine to find the best settings of unit model parameters to match experimental data that is measured on the plant.(Professional version only)

Graphics for Mineral Processors - graphics routines that are useful for the display of data sets produced by MODSIM and by other typical mineral processing applications.

BatchSim - a simulator for batch processes used for model testing and parameter estimation.(Professional version only)

Model Development Software Kit - a kit to develop and deploy models in MODSIM. Models can be written in Fortran or C. (Professional Version only)
