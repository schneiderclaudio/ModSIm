MODSIM 3.6.24 Professional

INSTALLATION

1 - Run SETUP.EXE in the CDROM and follow instructions to setup MODSIM.
2 - The instalation shoud create a directory <Jobs> in the instalation directory 
    in the previous step.  Default is C:\Program Files\Modsim_3_6_24_Pro\ so you should 
    have a C:\Program Files\Modsim_3_6_24_Pro\DemoJobs\ directory if the default 
    installation directory was used.

RUNNING A DemoJob

1 - Run Modsim from the Start Menu -> Program Files -> Modsim 3.6.24 Pro shortcut.
2 - Click on File then "Open an existing job" in the File menu.
3 - Load any job from the Jobs directory copied during the installation.
4 - Click on Run then "Run simulation" in the Run menu.
5 - After completion of calculation and output, click on View then Flowsheet.

GENERAL

The flyouts will give some mass balance  information about and around the 
units in the job.  Click with the right mouse button on any unit 
icon to see a more detailed output for that unit.
To view the system data (Particle types, sizes, etc. ) click on Edit then 
"Edit System Data".  Double click in a feed stream to see size distribution data.

To run on a network under WinNT/2000, users must set a MODSIM environment variable
containing the path information for the Modsim Working Directory. Users must have 
authority to read and write in the indicated folder.
